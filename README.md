# Lógica de Programación 1

## Descripción

Este proyecto consiste en crear un programa en JavaScript que solicita tres números al usuario, los analiza y los muestra ordenados.

El programa realiza las siguientes acciones:

- Solicita 3 números mediante `prompt`.
- Convierte los valores ingresados a tipo `Number`.
- Valida que los datos sean números válidos.
- Identifica:
  - El número mayor
  - El número intermedio
  - El número menor
- Muestra los números:
  - De mayor a menor
  - De menor a mayor
- Detecta si los números son iguales.

## Tecnologías utilizadas

- JavaScript
- HTML
